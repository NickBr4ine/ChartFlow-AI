# ChartFlow-AI
ChartFlow AI is a modern trading analysis platform focused on visual market intelligence.

The application combines real-time cryptocurrency market data, technical indicators, and AI-assisted insights to help traders analyze market structure more efficiently.

Built with TypeScript and Clean Architecture principles, the project is split into a NestJS `backend` and a Vite + TypeScript `frontend`, with Hexagonal Architecture, SOLID practices, and scalable design patterns.

Main features:
- Authenticated crypto market analysis UI
- Interactive candlestick charts
- Custom SMA plotting and automatic crypto variable price lines
- NestJS market analysis API with SMA domain services
- AI-generated educational market insights
- Binance market data integration
- Modular and scalable architecture
- Professional trading dashboard
- Educational-first approach (non-financial advice)

Tech Stack:
- TypeScript
- React / Vite
- Node.js
- NestJS
- TradingView Lightweight Charts
- Clean Architecture
- Hexagonal Architecture
- DTO & SOLID principles
- pnpm
- Husky

Package Manager:
This project uses pnpm only. Do not use npm or yarn for dependency management.

Setup:
```bash
pnpm install
pnpm prepare
```

Development Commands:
```bash
cd backend
pnpm dev
```

Open another terminal:

```bash
cd frontend
pnpm dev
```

Root quality commands:

```bash
pnpm build
pnpm lint
pnpm typecheck
pnpm test
```

Application:
- `cd backend && pnpm dev` starts the NestJS API on port 3333.
- `cd frontend && pnpm dev` starts the Vite dashboard on port 5173.
- The frontend proxies `/api/*` to `MARKET_API_BASE_URL` or `http://127.0.0.1:3333` by default.
- Development login defaults to user `demo` and password `chartflow`. Override with `AUTH_USERNAME`, `AUTH_PASSWORD`, and `AUTH_TOKEN_SECRET`.
- The dashboard uses deterministic mock candles for the MVP and does not execute orders.
- The API exposes `/api/auth/login`, `/api/health`, `/api/assets`, `/api/timeframes`, and protected `/api/market-analysis`.
- `/api/market-analysis` includes educational `aiInsight` generated by the fake provider by default.
- Future OpenAI integration can be enabled with `OPENAI_API_KEY` and optional `OPENAI_MODEL`.

Git Hooks:
