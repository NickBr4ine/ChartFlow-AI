# ChartFlow-AI
ChartFlow AI is a modern trading analysis platform focused on visual market intelligence.

The application combines real-time cryptocurrency market data, technical indicators, and AI-assisted insights to help traders analyze market structure more efficiently.

Built with TypeScript and Clean Architecture principles, the project uses a modular monolithic structure with Hexagonal Architecture, SOLID practices, and scalable design patterns.

Main features:
- Mocked crypto market analysis UI ready for future real-time data
- Interactive candlestick charts
- EMA 20 / 93 / 230 automatic plotting in the dashboard
- Fastify market analysis API scaffold with SMA domain services
- AI-generated educational market insights
- Binance market data integration
- Modular and scalable architecture
- Professional trading dashboard
- Educational-first approach (non-financial advice)

Tech Stack:
- TypeScript
- React / Next.js
- Node.js
- Fastify
- TradingView Lightweight Charts
- Clean Architecture
- Hexagonal Architecture
- DTO & SOLID principles
- pnpm
- Husky

Package Manager:
This project uses pnpm only. Do not use npm or yarn for dependency management.

Disclaimer:
ChartFlow AI is an educational and analytical tool only. It does not provide financial advice or execute trades.
